# SOX IT General Controls (ITGC) Assessment

A SOX IT General Controls assessment for a fictional fintech preparing for IPO, delivered
as an **Excel workbook** (control matrix + dashboard) and a **Word report**.

> Portfolio / lab project. *NorthStar Lending* is fictional; all data is invented.

## What's here
- **`SOX-ITGC-Assessment.xlsx`**:
  - **Control Matrix** — 16 ITGC controls across the four domains, with test results and
    deficiency severities, color-coded.
  - **Dashboard** — control-effectiveness rate, deficiency counts, a results-by-domain
    chart, and an **overall conclusion** computed by formula (returns the worst severity
    present — here, *Material Weakness*).
- **`SOX-ITGC-Report.docx`** — SOX/ICFR primer, the four ITGC domains, deficiency
  classification, and the findings report (including the segregation-of-duties material
  weakness) with remediation.

## Skills demonstrated
SOX 404 / ICFR · IT General Controls · deficiency classification (material weakness vs.
significant deficiency, PCAOB AS 2201) · segregation of duties · IT audit deliverables ·
Excel conditional formatting & formula logic.

## Standards referenced
